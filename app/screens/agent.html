How Your Recommendations Are Made

A LangGraph agent: 7-node StateGraph with conditional edges, reflection, and bounded refinement

When you browse, search and click courses, SmartReco's AI agent quietly builds a picture of what you're interested in — then walks through the pipeline below to pick your personalized courses. It's a stateful agent, not a wrapped LLM call: it reasons over your behavior, plans a retrieval strategy, grades its own results, and reflects on output quality.

Behavioral Analysis

Exponential decay weighting — recent events count more. TF-IDF-style search term scoring. Dwell-time multipliers for engagement depth.

Strategy Planning

Theory-of-user reasoning. Cold-start users get popular anchors. Focused learners get progression. Explorers get cross-domain picks.

Vector RAG Retrieval

ChromaDB with local ONNX MiniLM-L6-v2 embeddings. Category boosting, sub-topic boosting, level-preference filtering, seen-course exclusion.

Grading & Refinement

If retrieval score < 0.30, the agent broadens its query and retries (max 1 refine). Conditional edge prevents shipping irrelevant recs.

Persuasive Generation

Exactly ONE creative LLM call (Mesh API: tencent/hy3). Strategy-aware prompt angle. Diversity-enforced shortlist (max 2 per category).

Self-Reflection

Deterministic quality gate (no extra LLM call). Checks: generic-phrase detector, strategy-alignment, narrative-on-target. Regenerates once if failed.

Tech Stack

LangGraph StateGraph with 7 nodes, 2 conditional edges, bounded loops
ChromaDB Local ONNX MiniLM-L6-v2 embeddings, cosine similarity
Mesh API OpenAI-compatible gateway, model: tencent/hy3 (free tier)
FastAPI Async event buffer, background triggers, SSE streaming
SQLAlchemy Async SQLite, dual-write pattern (SQL + vector store)

Agent Triggers

Manual Refresh
User clicks "Refresh" on the AI Picks panel → POST /api/recommendations/refresh
Threshold Trigger
After 3+ behavioral events, the buffer auto-triggers the agent in background
Daily Digest (Proactive)
APScheduler runs the agent daily at 15:00 UTC for opted-in users
Speculative Pre-Compute
On login, if recs are stale (>1h), agent fires speculatively
